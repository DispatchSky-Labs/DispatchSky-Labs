Archived project

Sadiom Flow

Flight watchlists and ETD change alerts, built from aircraft-dispatch experience.

Live tracking and notifications have been retired. Sadiom Flow is preserved here as a portfolio case study.

Created by
Samuel Gonzalez
My role
Independent product design and development
Platform
Browser-based web application

The problem

When several flights need attention, repeated manual checks make it harder to notice which departure times have changed. Flow explored how a focused watchlist could make those changes easier to recognize.

What I built

  • A focused flight watchlist

    Flight lookup, saved watchlists, and a compact view of routes and estimated departure times.

  • Changes at a glance

    Readable indicators for new times, earlier or later departures, and ETD Met states, with recent alerts and optional desktop notifications.

  • Context for the information

    Source-freshness indicators and reminders to verify information in official operational sources.

Design approach

The interface prioritized a short, scannable flight list. Timing changes combined text, direction, and color so the meaning did not depend on color alone. A responsive layout kept the watchlist usable across desktop and mobile browsers.

The product brought together a browser interface, a server-side data service, periodic refreshes, and notification handling. My work covered the concept, aviation logic, workflow, interface, development, testing, deployment, and maintenance during its live operation.

Project status

Flow was released as a working web product. Its live service has now been retired, while this case study preserves the interface and the work behind it.
